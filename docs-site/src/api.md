# API documentation

The Rust API documentation is generated by `rustdoc` from the `///` and `//!` comments in the
source, and published next to this book.

| Crate | Link | What you find there |
| :--- | :--- | :--- |
| `spawn-at-core` | [spawn_at_core](api/spawn_at_core/index.html) | Geometry, the `Driver` trait and `Batch` types, the ready-wait state machine, settings |
| `spawn-at` | [spawn_at](api/spawn_at/index.html) | The CLI crate. It is a binary, so rustdoc documents all of its items, private ones too |
| `spawn-at-verify` | [spawn_at_verify](api/spawn_at_verify/index.html) | The verification harness (default features: without the `tui` module) |

`xtask`, the repository tooling, is not published. It is an internal binary with no public API; its
documentation builds cleanly but is left out of the site.

## What to expect

These pages are only as good as the comments in the code. Many modules have a short overview and
some have none (`docs/CODE_LAYOUT.md` lists the first `//!` line of every file, and which files have
no module comment). The comments were not rewritten for this site, apart from a few broken links
and a short overview for `spawn-at-core` and `spawn-at-verify`. Where a page and the code disagree,
the code wins.

To build the same pages yourself: `cargo doc --no-deps --workspace --exclude xtask --locked`, then
open `target/doc/spawn_at_core/index.html`.
