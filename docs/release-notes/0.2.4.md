# spawn-at 0.2.4: release notes

Released 2026-10-21. This is a patch release. It fixes some rough edges in the installer and updater, and it is more honest about which GNOME versions were tested.

After upgrading, `spawn-at update` works as before. The extension did not change (protocol 7), so you do not need to log in again for this release.

## What's new

- After a quiet background update changes the GNOME extension on Wayland, you now get a desktop notice. It asks you to log out and back in (#87). Before, nothing was said.
- `spawn` prints one reminder line until you have logged in again.

## What changed

- The notice about untested GNOME versions now lists which versions were tested. GNOME 50 is listed as partly tested. A first run of the release test on GNOME 50.1 passed 16 of 36 cases and failed 9, so GNOME 50 is not listed as fully tested.
- A development build now shows its version number on the first line of `spawn-at -V`.
- The release process now stops early if the tag and the crate versions disagree. It uses the changelog section as the release text when there is one.

## What was fixed

- A menu on a terminal with no keyboard no longer draws and then fails with a raw error. It now prints one line and asks you to run again with `--headless`.
- On a first install on Wayland, the confusing "exited with code 2" message is replaced by a plain one. It says to log out and back in.

## Known issues and upgrading

- The release process changes have not run on GitHub yet.
- The notice and the login reminder were run on a test setup only. They were not run on a real login, on other Shell versions or on X11.
- The full list is in the changelog: [CHANGELOG.md](../../CHANGELOG.md).
