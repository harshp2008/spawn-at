# spawn-at 0.2.3: release notes

Released 2026-10-21. This is a patch release. It fixes one bug where a window could be placed using the wrong instruction.

After upgrading, run `spawn-at update` (or `spawn-at install`), then log out and back in. You need both the new program and the new extension. One without the other behaves as before.

## What's new

- The extension has a new version of its protocol (7). It lets the program take back its own instruction. This is the base for the fix below.

## What changed

- Details not recorded. The changelog lists only the new protocol and the fix.

## What was fixed

- Before, `spawn` could leave an unused instruction waiting in the extension for 15 seconds. This happened when the app was already open and only passed the request to its running window. Then no new window appeared. The next window of that app was placed using the old instruction.
- Now `spawn` takes back its own instruction when no window claims it (#84, #85).

## Known issues and upgrading

- Not fixed: a window that appears within about 4 seconds after such an instruction.
- Not fixed: `--no-wait`, and a program that is killed. These still rely on the 15 second expiry.
- Not fixed: the older extension for GNOME 42 to 44.
- Tested on GNOME Shell 50.1 on Wayland with test windows. Not run on other Shell versions or on X11.
