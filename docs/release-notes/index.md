# Release notes

One page for each release, newest first. Each page says what is new, what changed, what was fixed and what is still unknown. The short list of every change is in [CHANGELOG.md](../../CHANGELOG.md).

A release without a page here fails the release check, so a new release always adds one.

- [0.2.4](0.2.4.md), 2026-10-21: clearer installer and updater messages, a log-out notice after a quiet update, and honest GNOME test status.
- [0.2.3](0.2.3.md), 2026-10-21: fixes a window placed with the wrong instruction after an app reused its open window.
- [0.2.2](0.2.2.md), 2026-10-21: support for GNOME Shell 49 and 50, and clearer errors when the extension is missing.
- [0.2.1](0.2.1.md), 2026-10-18: fixes for eight installer, updater and test-tool issues.
- [0.2.0](0.2.0.md), 2026-10-18: the stable 0.2 release, with the same code as 0.2.0-beta.6.
- [0.2.0-beta.6](0.2.0-beta.6.md), 2026-10-17: the installer's PATH advice is the same on every run and mentions logging out.
- [0.2.0-beta.5](0.2.0-beta.5.md), 2026-10-17: refusal on unsupported desktops, an install prompt, and the documentation site.
- [0.2.0-beta.4](0.2.0-beta.4.md), 2026-10-15: code restructured for other platforms, and an experimental Sway backend.
- [0.2.0-beta.3](0.2.0-beta.3.md), 2026-10-15: the install flow.
- [0.2.0-beta.2](0.2.0-beta.2.md), 2026-10-14: a cleanup release.
- [0.2.0-beta.1](0.2.0-beta.1.md), 2026-10-14: the first beta of the 0.2 series.
