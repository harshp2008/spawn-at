# spawn-at 0.2.2: release notes

Released 2026-10-21. This is a patch release. It adds support for GNOME Shell 49 and 50 and makes error messages clearer. Window placement itself did not change.

After upgrading, run `spawn-at update` (or `spawn-at install`), then log out and back in. This writes the new extension file and loads it.

## What's new

- The GNOME extension now lists GNOME Shell 49 and 50. Before, GNOME 50 marked the extension "out of date" and never loaded it, so every `spawn` printed an error.
- The maintainer tried GNOME 50.1 on Wayland by hand. The extension loaded and placed a window correctly.

## What changed

- The placement message now says more. It names the request, the area and the final screen position.
- The help text for `--pos` and `--offset` now says the position is counted from the `--area` rectangle. By default that is the work area.
- The documentation site got many layout and wording fixes (#63 to #80). Nothing in the program, the extension or the installer changed for these.

## What was fixed

- When the extension does not answer, the error now says why. It tells you if the extension is missing, disabled, out of date or too old.
- A missing extension no longer prints a wrong "protocol mismatch" warning.

## Known issues and upgrading

- GNOME 49 was not run. The older extension for GNOME 42 to 44 was not run either.
- The new error messages were not run on a live GNOME Shell.
- The full list is in the changelog: [CHANGELOG.md](../../CHANGELOG.md).
